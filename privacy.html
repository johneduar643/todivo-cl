Política de privacidad

Documento base: antes de comenzar ventas reales, el responsable adulto del negocio debe completar los datos legales y revisar este texto con la normativa aplicable en Chile.

1. Datos que podemos recibir

Para procesar un pedido, TODIVO CL puede recibir nombre, correo electrónico, teléfono y datos de entrega proporcionados por el cliente.

2. Para qué se usan

Los datos se utilizan para gestionar pedidos, coordinar la entrega, responder consultas y mantener registros operativos del negocio.

3. Pagos

Los datos de tarjetas no deben almacenarse en TODIVO CL. Cuando se habilite una pasarela de pago, el procesamiento deberá realizarse mediante el proveedor correspondiente.

4. Seguridad

TODIVO CL debe limitar el acceso administrativo y proteger las credenciales del servidor. Las contraseñas y claves privadas no deben publicarse en el repositorio.

5. Contacto

Las solicitudes relacionadas con datos personales deberán dirigirse al canal de contacto oficial que el negocio configure antes de iniciar operaciones.
